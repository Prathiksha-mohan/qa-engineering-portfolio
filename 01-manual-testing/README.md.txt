## Jira – Test Case Management and Defect Tracking

**Project:** Farmers Market QA Testing

Used Jira to organize manual testing activities and manage identified defects.

### Activities performed
- Created individual test case issues for signup and login feature.
- Created individual bug issues for identified defects.
- Added labels to categorize test cases and bugs.
- Organized issues using Jira workflow statuses.
- Used a Kanban board to visualize testing tasks and track issue progress.

### Evidence
Screenshots of the Jira project board, individual test cases, bug reports and issue list are included in the `jira-workflow/` folder.
