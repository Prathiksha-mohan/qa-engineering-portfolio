
# Bug Reporting – Farmers Market Application

## Overview
Bugs identified during manual testing were documented and managed using Jira.

## Bug Reporting Process
- Identified defects during manual testing.
- Created individual bug reports in Jira.
- Documented steps to reproduce.
- Recorded expected and actual results.
- Linked bugs to their corresponding test cases.

## Tools Used
- Jira
- Manual Testing

## Evidence
Screenshots of the Jira bug list, individual bug reports, and linked test cases are included in this folder.
