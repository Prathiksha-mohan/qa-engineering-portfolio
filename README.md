# QA Engineering Portfolio

Welcome to my QA Engineering Portfolio! This repository showcases my practical experience and learning in Software Quality Assurance through manual testing, API testing, test management, and test automation.

I created this portfolio using the **Farmers Market web application** as my testing project.

## Project Under Test

**Application:** Farmers Market Web Application

A web application that allows users to browse agricultural products, add products to a shopping cart, and place orders.

## Skills & Tools

- **Manual Testing:** Functional Testing, Negative Testing, Test Case Design
- **Test Management:** Jira
- **API Testing:** Postman, REST API Testing
- **Automation Testing:** Playwright, TypeScript
- **Cross-Browser Testing:** Chromium, Firefox, WebKit
- **Version Control:** Git, GitHub
- **Database Testing:** SQL

## Test Execution

To run the Playwright automation tests:

```bash
npm install
npx playwright install
npx playwright test
```

To view the Playwright test report:

```bash
npx playwright show-report
```
